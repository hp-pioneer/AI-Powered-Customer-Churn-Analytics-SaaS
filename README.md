# AI-Powered Customer Churn Analytics in SaaS Industry

## Project Overview

This project was completed as a capstone project for the **Data Science Course at Internshala Trainings**. The objective was to analyze customer churn in a SaaS environment by combining structured customer data with exit interview feedback.

The project applies **Python, SQL, NLP, and Power BI** to identify customer churn patterns, analyze exit reasons and customer sentiment, and translate the findings into actionable business recommendations for customer retention.

## Objectives

- Analyze customer churn patterns across key customer segments.
- Identify major reasons associated with customer exits.
- Analyze exit interview feedback using NLP techniques.
- Integrate structured customer data with exit interview information.
- Develop an interactive Power BI dashboard for churn analysis.
- Generate business recommendations to support customer retention.

## Tools & Technologies

- **Python** – Data cleaning, exploratory data analysis, NLP, and statistical analysis
- **SQL / BigQuery** – Data profiling, validation, and customer-interview linkage
- **NLP** – Exit reason and customer mood analysis
- **Power BI** – Interactive dashboards and comparative churn analysis
- **Jupyter Notebook** – Analysis and documentation

## Project Workflow

1. Data profiling and quality assessment
2. Customer data cleaning and validation
3. Exit interview text preparation and NLP analysis
4. Customer–interview data integration
5. Churn segmentation and exploratory analysis
6. Power BI dashboard development
7. Business insights and retention recommendations

## Key Findings

- The final customer-level analysis covered **3,244 unique customers**.
- **2,506 customers were identified as churned**, resulting in a customer churn rate of **77.25%**.
- Exit interview analysis covered **3,405 NLP records**.
- **Value** was the most frequently identified exit reason, followed by **Competitor** and **Support**.
- **Frustrated** was the most common customer mood, followed by **Disappointed**.
- Customers with higher numbers of support tickets showed higher observed churn rates.
- Early-tenure customers showed elevated churn compared with several longer-tenure groups.

These findings represent **observed patterns and associations in the analyzed data and should not be interpreted as causal relationships**.

## Business Recommendations

The analysis supports several potential retention initiatives:

- Establish segment-level churn monitoring.
- Investigate customers with repeated support interactions.
- Continuously track exit interview feedback and customer sentiment.
- Operationalize the dashboard for regular retention reviews.
- Integrate behavioral and product-usage data for future analysis.
- Develop predictive churn modeling as a future enhancement.
- Explore Customer Lifetime Value (CLV) and automated churn alerts.
